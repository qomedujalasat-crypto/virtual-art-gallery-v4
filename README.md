# Virtual Art Gallery V4

نسخهٔ چهارم نمایشگاه مجازی جشنواره طراحی و دوخت لباس دانش‌آموزی قم. این شاخهٔ توسعه بر پایهٔ نسخهٔ آزمایش‌شدهٔ V3 ساخته شده است.

## افزودن آثار
تصاویر را در پوشهٔ `images` قرار دهید؛ نام هر فایل باید کد اثر در نظرسنجی باشد. فایل `1.jpg` برای تصویر آغازین/سردر رزرو شده است.

## توسعه محلی
`npm install` سپس `npm start` برای اجرا و `npm run build` برای ساخت نسخهٔ نهایی.
